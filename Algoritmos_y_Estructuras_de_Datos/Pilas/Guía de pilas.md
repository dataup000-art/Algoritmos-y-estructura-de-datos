# Pilas

## Idea principal
Una pila trabaja con la regla **LIFO**: el último elemento que entra es el primero que sale. Es como una pila de platos: se retira primero el que está arriba.

## Operaciones
- **PUSH:** insertar un elemento en el tope.
- **POP:** retirar el elemento del tope.
- **Tope:** elemento que saldría primero.

La implementación puede variar. Conserva los nombres de atributos y métodos del código de cada ejercicio. Identifica qué variable señala el tope, cómo se conecta un nodo nuevo y qué cambia al insertar o retirar.

## Ejemplo 1: orden de salida
Si insertas `5`, `8` y `12`, salen en este orden: `12`, `8`, `5`.

## Ejemplo 2: operaciones
```text
PUSH 5
PUSH 8
POP
```
Después queda `5` en la pila y se retiró `8`.

## Para practicar
Dibuja la pila después de cada operación e indica cuál es el tope. Revisa también qué sucede al retirar de una pila vacía, según el código del ejercicio.
